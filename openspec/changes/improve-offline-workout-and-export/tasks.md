# Tasks

## 1. 动作选择和同步

- [ ] 1.1 在用户确认后，从同一来源产物构建 App 内可用目录，选择来源动作时立即本机保存并排队同步；验证无后端配置和已配置但不可达两种情况，且冷启动首次选择不需要预热缓存。
- [ ] 1.2 在隔离后端验证离线选择后保存计划或实际组、重启、恢复同步和再次选择；确认相同来源及类型只使用一个 ID，并更新应用指南的离线说明。

## 2. 训练卡片与换练

- [ ] 2.1 直接显示内置或可用来源动作图，移除重复计划／器械及完成状态文案，按有无备注显示编辑图标；实机核对有图有备注和无图无备注两种状态。
- [ ] 2.2 简化已完成组摘要和靠右的修改、撤销图标，给每个有效组添加分段圆点；实机核对双侧重量组、计时组、分段组及修改／撤销后的进度。
- [ ] 2.3 将换练入口放到卡片上，复用未完成目标替换规则并验证零完成组、部分完成、历史引用和重启路径；更新换练与订正的应用指南。

## 3. 训练结束规则

- [ ] 3.1 共用手动、自动及过期恢复的结束保存逻辑，保留实际结束时刻并清除休息或动作计时；验证未做任何组、跨日和真实完成时间未知的记录。
- [ ] 3.2 本机保存半小时失效期限并按系统能力调度；隔离环境验证断网超时、后台／重启结算、期限前更新、续练和过期回调不互相覆盖，更新运动记录说明。

## 4. 按项导出与分享

- [ ] 4.1 按 UTC+8 双端包含的日期范围和多选类别生成 ZIP，范围标明在线完整、缓存及缺失；解压核对同日边界、未同步训练、健康多页与未勾选项，以及没有设置和凭据。
- [ ] 4.2 在 App 增加独立入口、日期选择、多选、Android 文件保存和系统分享；实机以隔离资料验收导出的真实文件，并更新使用指南和包内字段说明。

## 5. 整体验收与交付

- [ ] 5.1 主助手用隔离 Android 应用和后端贯通离线加动作、换练、自动结束、恢复同步及分享 ZIP，核对所有可见 UI 变化；执行受影响的最小验证范围。
- [ ] 5.2 更新变更记录，构建正式签名 Release APK，核验签名、包名与不可调试属性，提交所完成的改动并交付 APK 路径。
