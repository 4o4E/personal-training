# Spec Delta

## ADDED Requirements

### Requirement: 首次选择来源动作可离线保存

App SHALL 在后端不可达或未配置时也允许从内置和随 App 提供的来源动作目录添加动作、换练或编辑计划。选择和保存 MUST 不依赖后端响应；本机改动走既有同步与冲突处理，同一来源动作不因离线选择产生重复身份。

#### Scenario: 从未选择的网站动作离线加入训练
- **WHEN** 手机上的已配置后端无法响应，用户搜索并选择一个此前未加入过的来源动作
- **THEN** 立即可填写并保存该动作的实际组，重启后结果仍在；后端恢复后该动作及训练正常同步，不产生重复动作

#### Scenario: 未配置后端时编辑计划
- **WHEN** 用户从未配置后端也未下载过网站目录，在计划里选择一个随 App 提供的来源动作
- **THEN** 动作和计划可直接在手机保存，不依赖教学图片加载完成
