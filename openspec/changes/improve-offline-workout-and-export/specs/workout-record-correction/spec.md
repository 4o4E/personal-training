# Spec Delta

## MODIFIED Requirements

### Requirement: 训练内直接更换剩余动作

训练页面 SHALL 在动作卡片提供直接更换剩余动作的入口，无须展开更多操作、先追加动作或离开训练页面。已完成组保留旧动作，尚未执行的内容使用用户选择的新动作，未来模板不变。

#### Scenario: 已完成两组后换练其他动作
- **WHEN** 原动作有四组目标且完成两组，用户更换剩余动作
- **THEN** 原两组保留动作身份和实际数据，新动作仅承接确认的剩余训练，不复制完成组，不产生虚构完成时间；旧动作不再提示完成已转移的组

#### Scenario: 未执行动作更换
- **WHEN** 用户为尚无完成组的动作选择新动作
- **THEN** 本次训练的原位置显示新动作，不保留旧动作作为待练内容；原计划副本及未来模板不变，保存后可离线继续并同步
