# Proposal

## Why

后端不可达时，从网站目录添加新动作会被在线写入阻断。训练页难以一眼辨认或更换动作，忘记结束训练会让记录持续开放，手动补结束又会把操作时刻误记成实际结束时间；现有整包备份不能代替按日期和项目分享的导出。

## What Changes

- 本次训练及计划中的动作选择和保存留在手机；后端不可达只影响同步，不阻断新增或更换动作。
- 训练卡片将当前动作动图与实际录入并排，支持原位切换单位和只读的公斤换算；简化顶部、计划、器械、备注、完成组及进度条的呈现，并提供直接换练入口。
- 手动完成训练时，用最后一组实际训练的完成时间；连续半小时没有训练更新时自动完成有实际组的训练。
- 增加按日期范围和多个数据项目生成并分享 ZIP 的入口，覆盖训练记录、步数、热量消耗、心率等数据，与现有备份分开。

## Capabilities

### New Capabilities

- `selective-data-export`：按日期与所选数据类别生成可分享的资料 ZIP。

### Modified Capabilities

- `cloud-training-state`：本机解析并保存首次添加的来源动作，之后才同步。
- `training-session-execution`：动作图、记录摘要、分段进度和训练完成时间。
- `workout-record-correction`：在训练卡片直接更换动作，并保留已有实际组。

## Impact

影响 Android 训练页、选择器、设置导出以及既有动作目录与本机同步流程。不改计划模板、个人资料、生产环境和数据库表结构；不替换现有备份与恢复功能。
