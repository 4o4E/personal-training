# Spec Delta

## Purpose

帮助首次进入的用户理解训练、计划调整与记录流程，并学会配置自己的后端地址和唯一 token；教程保持可重看、可稍后继续，不把说明流程变成覆盖已有配置或阻止离线使用的条件。

## ADDED Requirements

### Requirement: 首次进入提供开始教程

应用 SHALL 在首次使用时提供中文开始教程，说明三个主要功能、如何选择方案以及训练提醒所需授权，并在完成或明确跳过后记住状态。菜单 SHALL 提供重新查看入口。

#### Scenario: 首次使用后重新打开
- **WHEN** 用户完成或明确跳过教程后重新打开应用
- **THEN** 不再被强制重复教程，仍能从菜单重新查看

### Requirement: 解释并引导自有后端配置

教程 SHALL 说明手机可访问的后端地址、唯一 token 的取得与填写方式、保存并同步的作用，以及离线使用与同步的区别。用户 SHALL 可以稍后连接；教程 MUST 不输出 token 或把其写入说明、日志和训练资料。

#### Scenario: 暂时不配置后端
- **WHEN** 首次使用者在后端步骤选择稍后连接
- **THEN** 可继续选择计划并离线使用，之后能从菜单设置填写地址和 token

### Requirement: 已有用户不被要求重新配置

教程 MUST 识别并保留现有后端连接、方案和训练资料，不因引入首次使用状态而清空或自动替换数据；已经配置的内容 SHALL 如实显示，无需再次输入。

#### Scenario: 已部署后端的用户升级
- **WHEN** 已有连接与训练方案的用户升级并查看教程
- **THEN** 原连接与方案保持，教程不要求先重置数据、重新填写 token 或强制生成另一套方案
