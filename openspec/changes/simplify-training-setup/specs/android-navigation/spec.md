# Spec Delta

## Purpose

使日常操作集中在开始训练、调整计划和查看运动记录，辅助配置通过左上角菜单访问，教学出现在用户实际选择或执行动作的位置，减少与当前任务无关的独立入口。

## ADDED Requirements

### Requirement: 底部仅提供三个训练入口

应用底部导航 SHALL 仅提供“开始训练”“调整计划”“运动记录”，分别承载本次及后续训练、方案与计划调整、实际历史；切换页面 MUST 不丢失当前方案选择或进行中的训练状态。

#### Scenario: 切换后返回训练
- **WHEN** 用户从开始训练切换到调整计划或运动记录后返回
- **THEN** 仍显示原来选择的方案和进行中的训练，底部没有动作库或健身房入口

### Requirement: 辅助功能从左上角菜单进入

应用 SHALL 在左上角提供菜单，将设置、可选健身房及教程收纳其中，原有后端连接、同步、提醒权限、导入导出、应用更新和器械维护功能 MUST 仍可访问。

#### Scenario: 管理健身房或后端
- **WHEN** 用户需要维护器械或修改后端连接
- **THEN** 可从左上角菜单进入对应功能，退出后返回原训练主页面，不新增底部导航项

### Requirement: 教学入口属于动作使用场景

应用 MUST 移除独立动作教学主入口，在动作选择、计划预览与实际训练处提供对应教学，保留肌肉图解、器械要求、实际图片与中文执行步骤，包含拉伸动作。

#### Scenario: 训练中查看教学
- **WHEN** 用户在训练列表打开某动作教学并返回
- **THEN** 查看的是该动作的图解和执行方式，返回后已有完成组及休息状态保持不变
