# Spec Delta

## Purpose

为训练、计划配置和历史查看提供统一可读的浅色与深色外观，允许跟随系统或固定选择，并保持跨页面和重新启动后的偏好一致，不影响正在进行的训练或原生计时。

## ADDED Requirements

### Requirement: 支持系统及手动外观选择

应用 SHALL 提供跟随系统、浅色和深色三种外观设置，默认跟随系统，并持久保存用户选择；固定深色或浅色时 MUST 不被系统外观变化覆盖。

#### Scenario: 固定深色并重新打开
- **WHEN** 用户选择深色，退出并重新打开应用
- **THEN** 应用保持深色，且设置准确显示当前选择

#### Scenario: 跟随系统切换
- **WHEN** 用户选择跟随系统，系统切换浅色或深色
- **THEN** 应用使用对应外观，不要求重新配置训练方案

### Requirement: 主题在实际操作表面保持一致

主要页面、菜单、教程、表单、弹窗、状态提示和系统栏 SHALL 随所选主题适配，保持文字、控件和肌肉图解可辨认；动作原图和器械照片 MUST 不被主题反色改变内容。

#### Scenario: 深色模式查看教学及编辑计划
- **WHEN** 用户在深色模式打开动作教学、计划编辑和确认弹窗
- **THEN** 文字及控件可读，肌肉图与动作图片完整，系统栏图标与背景不会同色而难以辨认

### Requirement: 外观变化不改变训练状态

切换外观 MUST 不重置方案选择、已完成组、原始读数、计时截止时间或连接配置。

#### Scenario: 组间休息时切换外观
- **WHEN** 已有组间休息在计时，用户切换外观后返回训练
- **THEN** 原训练和截止时间保持，到时仍发送普通通知
