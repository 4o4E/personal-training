# Spec Delta

## Purpose

明确三个主入口与辅助页面的导航关系，使设置与每日记录拥有独立页面和可预测的返回行为；用户在设置、计划、教学和历史之间切换时，不丢失正在进行的训练、实际读数与休息计时。

## ADDED Requirements

### Requirement: 设置使用独立路由

设置 MUST 是从左上角菜单进入的独立页面而不是覆盖主页面的弹窗，具有标题与返回入口，不新增底部主导航项；系统返回与页面返回 SHALL 回到进入设置前的位置。

#### Scenario: 休息中进入设置
- **WHEN** 用户正在休息时进入设置，调整外观后返回
- **THEN** 返回原训练页面，已完成组、尚未提交的实际读数与原倒计时截止时间保持不变

### Requirement: 每日记录使用独立日期路由

从运动日历选择日期 SHALL 进入该日期的记录页面，返回时保留原日历月份与选择日期；详情与设置均不得增加第四个底部主入口。

#### Scenario: 查看上月训练再返回
- **WHEN** 用户翻到上月并点击某个训练日，查看详情后返回
- **THEN** 仍展示上月日历和原选择日期，不重置到当月或结束当前训练

### Requirement: 三个主入口职责明确

开始训练 MUST 负责实际执行和记录，调整计划 MUST 承载所有计划配置，运动记录 MUST 承载日历与历史；现有教学、健身房、连接配置、备份和更新功能仍可通过对应使用场景或菜单访问。

#### Scenario: 没有可执行安排
- **WHEN** 用户进入开始训练而当前没有可执行计划
- **THEN** 显示前往调整计划的入口，不在训练页嵌入分化选择、候选方案或计划编辑表单

### Requirement: 启动图标与应用名称清晰区分

启动器图标 MUST 使用简洁、居中的斜向哑铃图形，SVG是图形来源，Android自适应前景图形与SVG保持相同几何和配色；正式版名称 MUST 为“个人训练”，验证版名称 MUST 为“个人训练·验证”，均通过 `string/app_name` 提供。

#### Scenario: 查看安装后的应用标识
- **WHEN** 用户在启动器查看正式版或验证版应用
- **THEN** 两个版本均显示源自SVG的哑铃启动图标，正式版显示“个人训练”，验证版显示“个人训练·验证”
