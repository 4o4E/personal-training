# Spec Delta

## Purpose

明确三个主入口与辅助页面的导航关系：设置使用独立页面，每日记录在日历上方弹窗展示；用户在设置、计划、教学和历史之间切换时，不丢失正在进行的训练、实际读数与休息计时。

## ADDED Requirements

### Requirement: 设置使用独立路由

设置 MUST 是从左上角菜单进入的独立页面而不是覆盖主页面的弹窗，具有标题与返回入口，不新增底部主导航项；系统返回与页面返回 SHALL 回到进入设置前的位置。

#### Scenario: 休息中进入设置
- **WHEN** 用户正在休息时进入设置，调整外观后返回
- **THEN** 返回原训练页面，已完成组、尚未提交的实际读数与原倒计时截止时间保持不变

### Requirement: 每日记录使用日期弹窗

从运动日历选择日期 SHALL 在日历上方打开该日期的记录弹窗，不进入独立路由；弹窗提供日期标题及内部滚动，不显示顶部关闭按钮。点击弹窗外侧或系统返回 SHALL 关闭弹窗并保留原日历位置与选择日期。详情不增加底部主入口，原有重量修改及自定义运动编辑删除能力保持。

#### Scenario: 查看上月训练再关闭
- **WHEN** 用户滚动到上月并点击某个训练日，查看弹窗后关闭
- **THEN** 仍展示原来的日历位置，不重置到当月，不结束当前训练；详情中的编辑操作不使日历重新定位

### Requirement: 三个主入口职责明确

开始训练 MUST 负责实际执行、当天完成结果及修改，调整计划 MUST 承载所有计划配置，运动记录 MUST 承载日历与历史。开始训练不提供重复的计划调整入口；记录其他运动的新增入口集中在左上角菜单。教学、健身房、连接配置、备份和更新仍通过对应使用场景或菜单访问。

#### Scenario: 新一天进入训练页
- **WHEN** 用户已有分化及计划或可复用的同类历史，新一天进入开始训练
- **THEN** 直接显示当天可记录的动作清单，不显示未安排、待开始按钮、重复调整入口或方案选择表单；底部调整计划导航保持可用

### Requirement: 启动图标与应用名称清晰区分

启动器图标 MUST 使用简洁、居中的斜向哑铃图形，SVG是图形来源，Android自适应前景图形与SVG保持相同几何和配色；正式版名称 MUST 为“个人训练”，验证版名称 MUST 为“个人训练·验证”，均通过 `string/app_name` 提供。

#### Scenario: 查看安装后的应用标识
- **WHEN** 用户在启动器查看正式版或验证版应用
- **THEN** 两个版本均显示源自SVG的哑铃启动图标，正式版显示“个人训练”，验证版显示“个人训练·验证”
