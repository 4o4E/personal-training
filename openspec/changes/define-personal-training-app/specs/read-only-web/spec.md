# Spec Delta

## Purpose

明确未来浏览器支持的用途是查看个人训练数据，复用自有后端已经提供的数据能力，而不是维护另一套训练执行流程，从而优先保障安卓原生训练和休息提醒的可靠性。

## ADDED Requirements

### Requirement: 浏览器支持仅限数据浏览

未来提供浏览器客户端时，该客户端 SHALL 用于浏览训练计划与记录等数据，不承担训练执行、完成组、组间休息提醒或计划编辑等修改操作；浏览器能力不得成为安卓原生训练功能的前置条件。

#### Scenario: 在浏览器中查看历史训练
- **WHEN** 用户将来通过浏览器客户端查看已同步的训练记录
- **THEN** 可以浏览后端中的数据，不需要在浏览器内重新执行训练，也不会提供另一套完成组和休息通知流程

### Requirement: 浏览器复用同一后端的数据

未来浏览器的数据浏览 SHALL 通过同一自有后端的鉴权业务接口获取资料，不建立独立的训练数据来源。

#### Scenario: 查看安卓训练后已同步的记录
- **WHEN** 安卓端的训练记录已成功同步，用户在浏览器客户端读取该记录
- **THEN** 浏览器展示同一份实际训练数据及原始单位，而不是一份另行手工维护的记录
