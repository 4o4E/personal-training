# Spec Delta

## Purpose

让拉伸候选随实际选择的训练动作和健身房器械条件变化，同时保留用户对训练顺序的控制；匹配到候选不等于已经将其加入训练计划，也不默认在每次训练末尾插入拉伸段。

## ADDED Requirements

### Requirement: 自动匹配但不自动插入拉伸

系统 SHALL 根据所选训练动作和部位推荐适合当前条件的拉伸；用户或助手选择候选并决定加入位置，系统不得默认生成末尾拉伸段。

#### Scenario: 查看本次训练的拉伸候选
- **WHEN** 用户选择训练动作并打开对应拉伸推荐
- **THEN** 显示相关拉伸及教学和可用条件，训练列表保持不变，直到用户或助手明确加入某个候选

### Requirement: 拉伸候选可替换并使用自身计量

系统 SHALL 尽可能提供多个适合条件的拉伸选择，保留各动作的时长、次数及左右侧要求；加入后仍可更换或调整位置。

#### Scenario: 选择拉伸并调整顺序
- **WHEN** 用户将一个按左右侧计时的拉伸加入指定位置，再将其移动到其他位置
- **THEN** 训练列表保持用户选定的顺序，拉伸的左右侧与计时要求不改变为普通负重重复次数
