# Spec Delta

## Purpose

将 N 分化表示为有顺序的训练内容，使用户能够依据恢复情况休息、指定后续日期或暂不指定日期，并在实际完成训练之后推进到下一项，而不将分化数量误解为固定的每周训练次数。

## ADDED Requirements

### Requirement: 完成训练后推进分化顺序

系统 SHALL 支持配置有序的 N 项分化训练及对应部位，实际完成训练后才推进到下一项；休息、预览计划或取消训练不得被视为完成。

#### Scenario: 推拉腿中间休息
- **WHEN** 用户完成推日后休息一天，期间没有完成其他训练
- **THEN** 下一项仍是拉日，不因日历经过一天而跳到腿日

### Requirement: 日期安排可选

计划 SHALL 允许指定日期；未指定日期的后续内容按训练顺序展示，不自动假定用户每天训练。

#### Scenario: 预览未指定日期的后续安排
- **WHEN** 用户配置分化顺序但未给后续计划指定日期
- **THEN** 应用展示下次及后续训练内容和部位，不凭空显示已经承诺的训练日期

### Requirement: 计划可按器械替换动作

系统 SHALL 在保持分化训练部位可见的同时允许选择或替换动作，候选结合健身房可用器械并提供教学。

#### Scenario: 更换下一次训练的器械动作
- **WHEN** 用户查看下次训练并替换某项动作
- **THEN** 可以选择适用器械的候选并查看教学，训练顺序不因替换动作而自动前进
