# Spec Delta

## Purpose

让用户在手机应用内直接检查正式版本、查看适合用户阅读的更新说明并下载安装包，通过安卓系统确认完成覆盖更新，不依赖助手手动传送 APK，也不要求登录 GitHub 或先升级训练后端。

## ADDED Requirements

### Requirement: 手动检查公开正式版本

应用 SHALL 在中文设置页面提供当前版本与检查更新入口，直接查询现有公开仓库的最新正式 Release。更新判定 MUST 使用内部版本号，不使用字符串排序；草稿、预发布版本及不高于当前安装的版本 MUST 不作为可升级版本。

#### Scenario: 存在更高版本
- **WHEN** 用户点击检查更新且公开正式版本的内部版本号更高
- **THEN** 应用显示新版本、更新说明和下载入口，无需训练后端或 GitHub 登录

#### Scenario: 已经是最新版本
- **WHEN** 正式版本的内部版本号不高于当前安装
- **THEN** 应用显示已是最新版本，不提供降级安装入口

#### Scenario: 检查请求失败
- **WHEN** 查询正式版本发生网络或发布资料读取错误
- **THEN** 应用显示检查失败，允许用户重新检查，不将错误显示为已经是最新版本

### Requirement: 下载结果与所选正式版本一致

应用 SHALL 在用户确认后下载所选版本的 APK，并显示实际进度和下载结果。安装前 MUST 验证下载完整性，以及安装包身份、签名和内部版本号与预期一致；失败的下载或验证 MUST 不进入安装步骤。

#### Scenario: 完整下载更新
- **WHEN** 用户选择下载已发现的正式版本且下载正常完成
- **THEN** 应用显示完成状态，确认 APK 与该正式版本相符，并提供安装操作

#### Scenario: 下载中断或文件不符
- **WHEN** 下载中断，或取得的文件与预期版本或完整性不符
- **THEN** 应用明确显示失败，不尝试安装该文件，允许用户重新下载

### Requirement: 使用安卓系统确认安装

应用 MUST 通过安卓系统安装界面发起更新，不要求用户寻找下载文件。尚未允许本应用安装 APK 时 SHALL 提供系统授权入口，返回后可以继续安装；安装由用户确认。

#### Scenario: 尚未允许安装 APK
- **WHEN** 用户点击安装且系统尚未允许本应用安装 APK
- **THEN** 应用打开对应授权页面，授权返回后仍可继续安装已下载文件

#### Scenario: 覆盖安装成功
- **WHEN** 用户在系统界面确认安装已验证的新版本
- **THEN** 应用升级为该版本，既有训练计划、实际记录和连接配置保留

### Requirement: 更新操作与训练数据独立

检查、下载和取消系统安装 MUST 不更改训练记录或分化进度，也不阻止正常训练及原生提醒。更新所用的 GitHub 请求 MUST 不携带训练后端 token。

#### Scenario: 用户取消安装
- **WHEN** APK 已下载但用户取消系统安装
- **THEN** 当前应用版本和训练资料保持不变，用户可以继续训练或再次安装
