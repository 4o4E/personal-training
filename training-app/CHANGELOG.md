# 变更记录

## 1.0.0

- 提供完整中文 Android 原生训练应用、Ktor 自有后端和独立 SQLite 数据。
- 支持可配置 N 分化、实际健身房及器械、可选日期计划、未来部位预览与动作替换。
- 收录中文图解教学与按部位及器械匹配的训练、动态及静态拉伸；拉伸由用户选择并指定加入位置。
- 按组保留 kg / lb、单只 / 单侧 / 总重量和负重 / 助力，区分计划目标及真实完成结果。
- 支持完整离线记录、完成及取消、开始时计划保存、联网同步和明确的版本冲突选择。
- 使用安卓定时唤醒发送休息与拉伸到时普通通知，提示音和振动遵循通知设置，展示授权状态及对应系统入口。
- 提供版本化 JSON 与素材 ZIP 备份、开放业务接口、Python CLI 和项目级训练助手 skill。
- 提供 GitHub Actions 后端镜像构建、运行检查及 GHCR 发布；Compose 拉取 latest 镜像，由用户手动部署并保留持久数据。
