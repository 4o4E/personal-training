# 变更记录

## 0.0.2

- 默认从三、四、五分化中选择整轮计划，提供三种器械取向和动作数量、组数选择，按实际内容说明部位、器械与训练量差异。
- 支持完整预览后一次保存整轮计划，再按日调整或替换；力量与拉伸分别计数，无日期分化计划完成一轮后可以继续使用。
- 底部仅保留开始训练、调整计划及运动记录；设置、可选健身房和教程收纳到左上角菜单，教学保留在选择、预览和训练中。
- 新增中文首次教程和自有后端连接步骤，既有资料可以继续使用；支持跟随系统、浅色和深色外观。
- 按方案保存每项循环计划的本机选择，保持已有任意 N、指定日期、原始 kg/lb、开始时计划和独立实际记录。

## 0.0.1

- 提供完整中文 Android 原生训练应用、Ktor 自有后端和独立 SQLite 数据。
- 支持可配置 N 分化、实际健身房及器械、可选日期计划、未来部位预览与动作替换。
- 收录中文图解教学与按部位及器械匹配的训练、动态及静态拉伸；拉伸由用户选择并指定加入位置。
- 按组保留 kg / lb、单只 / 单侧 / 总重量和负重 / 助力，区分计划目标及真实完成结果。
- 支持完整离线记录、完成及取消、开始时计划保存、联网同步和明确的版本冲突选择。
- 使用安卓定时唤醒发送休息与拉伸到时普通通知，提示音和振动遵循通知设置，展示授权状态及对应系统入口。
- 提供版本化 JSON 与素材 ZIP 备份、开放业务接口、Python CLI 和项目级训练助手 skill。
- 在应用设置中检查正式更新，查看说明和下载进度，下载后通过系统确认覆盖安装并保留训练资料。
