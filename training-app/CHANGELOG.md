# 变更记录

## 0.0.6

- 统一版本号 `0.0.6` 生成签名 APK、后端 ZIP、采集器 ZIP 与 `update.json`；CI 覆盖采集器和明确列出的 `misports/milib`、schema、依赖来源，发布镜像复用对应 Release 运行包并提供版本与 `latest` 标签。
- 增加独立服务器采集器及私有部署目录。首次使用工作区SQLite一致性副本执行 `publish` 首推既有历史，不登录小米云；配置凭据后启动服务执行真实采集并每小时重叠增量。采集、提交进度和轮换凭据保存在私有目录。公开制品不含源资料、个人数据或凭据。
- 健康数据在运动记录内查看，顶部仅保留一张同步卡；提供真实阶段状态与重试、日期健康概览和可选运动起止区间。推拉腿自由分类使用易辨颜色。
- 业务与备份格式升级为 v6，读取 v1–v5；完整健康备份由后端在线处理，本机导出仅包含已缓存范围。
- 生产更新前备份手机与后端资料，先升级后端/采集器并核对，再覆盖安装同版APK；回退时同步恢复升级前双端备份及匹配版本。发布镜像不表示生产已部署。

## 未发布

- 运动日历按连续周行滚动，月底和月初共用一行，星期标题固定并按实际可预览的末日期显示月份范围；至少显示当前月，不增加多余空白月份，保留连续滚动及关闭日期弹窗后的列表位置。
- 日期格统一约64dp高并保留日期、单行摘要和组数；今天保留独立底色，若当天有计划则只绘1dp虚线，否则绘1dp实线。预览窗口起点统一按今天是否存在含实际组的训练决定：有则从明日起，无则从今天起；窗口内明确日期计划优先于轮换预览。实际预览仍不写入训练记录或推进轮换。
- 从左上角菜单新增其他运动，在每日详情编辑和删除。
- 每日训练按 UTC+8 日期直接进入当天唯一记录：继续当天进行中的训练，或执行当天准备好的计划；无需「开始训练」确认，也无需另行安排每天的训练。旧日期仍 active 不阻挡新日；当天完成后可直接继续未完成的目标，只有需要超出原定目标时才明确追加待执行组。所有其他计划调整统一从「调整计划」进入。
- 当天记录修改可编辑已有组的重量、原始单位、次数、拉伸时长及反馈，支持逐段修改并重新计算整组次数；超出计划的追加组明确作为待执行目标。修改离线保存并同步，保留完成状态、计划、时间、组数及侧别，不启动休息计时或推进轮换。
- 每个日期统一使用相同日历容器，未来日期仅以虚线区分；点选日期在日历前方打开可滚动弹窗，展示当天唯一训练记录及独立的其他运动，并可关闭或系统返回；弹窗保留历史重量编辑与运动编辑删除。
- 日期详情弹窗不显示关闭按钮，点击外侧或系统返回即可关闭；训练时间区间及组完成时间仅显示时分，活动日期不重复显示；组明细取消序号，并以铅笔图标编辑可修改的历史组。
- 完整备份升级为 v5，仍可读取 v1–v5；每日训练按日期合并为唯一记录并保留既有来源。明确替换 v5 备份会完整恢复其中的同日训练记录，可撤销备份后该日新增的来源、动作、目标及执行状态；默认合并不替换已有不同内容。升级前先备份并停用旧应用，再更新配套后端，最后覆盖安装新版应用后打开；后端启动时自动归并已有同日记录。旧版客户端不能继续读取或同步使用 v5 的资料。

## 0.0.5

- 运动日历连续上下滚动月份，首次定位当前月并在返回时保留位置；范围从最早实际训练或自定义运动月份延伸至今天加当前分化项数天，未配置分化时截止当前月。日期格固定高度，长名称单行省略。
- 日期格区分实际记录与未来分化预览：实际训练显示开始时分类和真实完成组数，自由锻炼简称「自由」；自定义运动显示名称但不增加力量组数。未来使用虚线样式，明确日期的未执行计划优先；预览仅派生展示，不建立日程、不写入完成记录或消费手动轮换。相同日期多个明确计划均保留展示，无法唯一接续时不虚构轮换结果。
- 可从运动记录或每日详情新增、编辑和删除自定义运动，填写名称和日期，并选填分钟时长、公里距离及备注，时长和距离支持小数。记录按原生秒数和米数保存并在详情完整显示，不转换成训练会话或推进分化；使用通用离线保存、修订冲突、同步与备份。每日详情同时列出当天全部训练与其他运动，并保留已完成组的历史重量编辑。
- 完整备份使用 v4 并读取 v1–v4。创建或导入自定义运动前，先备份资料，再将客户端和配套后端一并升级到支持 activity 与 v4 的版本；旧版本不能继续读取新增运动资料。
- OxygenOS 支持设备显示原生收起倒计时与正向额外休息；设置提供实时活动显示授权入口。
- 同次训练同一动作的后续组默认沿用最近一次实际次数、重量与原始单位，未提交草稿优先，首组使用计划目标并保持计划休息时间；提供常用重量选择与加减输入。
- 休息到时使用系统闹钟音量和勿扰策略，启动可停止的持续振动及可选循环声音；应用和通知均可停止提醒，停止状态持久保存，额外休息继续计时。
- 历史训练按实际日期接续可对应的分化项目，修改旧读数不改变轮换顺序；调整计划可直接指定下次部位，历史详情支持纠正实际重量并保留原始单位和分段结果。

## 0.0.4

- 运动记录日历按日期汇总实际完成组数并显示当时保存的训练分类；同日多条训练合并组数、保留不同分类，分类缺失时显示「自由锻炼」，日期格不再展示记录条数、长训练名称或同步信息。
- 每日日志以训练分类为标题，展示原生动作、实际组明细与整理后的反馈，不显示历史来源原文。开始训练时保存对应分化的实际项目名，后续修改方案不改写既有训练分类；自由计划不强行归类。
- 保留 kg/lb 原始重量与明确的重量含义，未知含义仅显示数值和原始单位；覆盖安装后仍可读取已有本机缓存。
- 备份格式升级为 v3，读取 v1/v2/v3，并在读取旧备份时移除废弃的历史来源原文。

## 0.0.3

- 设置作为独立导航页面并保留主入口状态；日期详情在运动日历上以弹窗呈现，可系统返回关闭。
- 整轮方案与每项选用计划保存到云端安排；开始训练仅执行已安排的下一项，未来计划与本次剩余内容使用不同入口。
- 保留指定日期训练作为已安排轮换项，并在全部计划页保留独立安排的开始入口；未选入云端安排的循环模板不从训练页直接启动。
- 运动记录使用连续周日历和日期弹窗；月份随可见日期变化，日期格可滚动显示当天实际训练、独立运动和未来预览，详情展示全部记录；主页面区分同步状态、待上传改动、冲突及素材状态。
- 训练逐组显示实际完成进度，已完成组可收起并修正；修正已完成结果不重启休息计时。
- 启动主动同步，离线仍可使用本机安排；冲突按方案、训练项与计划名称展示双方内容，等待明确选择后同步。历史按实际完成组派生日历日期，保留未知开始时间与组内多段结果。
- 休息倒计时使用前台服务和原截止时间，页面与普通通知到时显示正向额外休息；通知权限说明区分通知显示与精确定时唤醒，勿扰遵循系统设置。支持设备收起状态的持续计时展示仍待实测。
- 通知点击可通过 `training.destination=workout` 返回训练；实时活动能力取决于系统版本与权限，普通通知不等同原生实时活动。
- 一加9R已完成主要流程真机验收，包括分化与轮换、未来计划与本次训练隔离、逐组及拉伸记录、离线同步与冲突、浅色深色日历、普通通知倒计时及点击返回。当前计时实现已验证前台与桌面顶部提醒、熄屏到时通知、正向额外休息、重复返回不重复提醒、拉伸到时结束及计时资源清理。支持设备的原生收起状态持续计时与到时行为仍待独立验收；一加9R普通通知证据不代表该能力已通过。
- 增加以 `branding/app-icon.svg` 为图形来源的启动器哑铃图标；正式版名称为“个人训练”，验证版为“个人训练·验证”。
- 历史记录支持保留只有日期而无开始时间的记录，不补造时间；保留单组内多段降重结果。备份使用 v2 格式并兼容读取 v1/v2。
