# 变更记录

## 0.0.3

- 将设置与每日记录详情作为独立导航页面；保留三个主入口的状态，支持系统返回与页面返回。
- 整轮方案与每项选用计划保存到云端安排；开始训练仅执行已安排的下一项，未来计划与本次剩余内容使用不同入口。
- 保留指定日期训练作为已安排轮换项，并在全部计划页保留独立安排的开始入口；未选入云端安排的循环模板不从训练页直接启动。
- 运动记录使用日历和每日详情；月份导航保持可访问，日期网格可滚动并完整显示当日前两次训练名称，详情展示全部记录；主页面区分同步状态、待上传改动、冲突及素材状态。
- 训练逐组显示实际完成进度，已完成组可收起并修正；修正已完成结果不重启休息计时。
- 启动主动同步，离线仍可使用本机安排；冲突按方案、训练项与计划名称展示双方内容，等待明确选择后同步。历史按实际完成组派生日历日期，保留未知开始时间与组内多段结果。
- 休息倒计时使用前台服务和原截止时间，页面与普通通知到时显示正向额外休息；通知权限说明区分通知显示与精确定时唤醒，勿扰遵循系统设置。支持设备收起状态的持续计时展示仍待实测。
- 通知点击可通过 `training.destination=workout` 返回训练；实时活动能力取决于系统版本与权限，普通通知不等同原生实时活动。
- 一加9R已完成主要流程真机验收，包括分化与轮换、未来计划与本次训练隔离、逐组及拉伸记录、离线同步与冲突、浅色深色日历、普通通知倒计时及点击返回。当前计时实现已验证前台与桌面顶部提醒、熄屏到时通知、正向额外休息、重复返回不重复提醒、拉伸到时结束及计时资源清理。支持设备的原生收起状态持续计时与到时行为仍待独立验收；一加9R普通通知证据不代表该能力已通过。
- 增加以 `branding/app-icon.svg` 为图形来源的启动器哑铃图标；正式版名称为“个人训练”，验证版为“个人训练·验证”。
- 历史记录支持保留只有日期而无开始时间的记录，不补造时间；保留单组内多段降重结果。备份使用 v2 格式并兼容读取 v1/v2。

## 0.0.2

- 默认从三、四、五分化中选择整轮计划，提供三种器械取向和动作数量、组数选择，按实际内容说明部位、器械与训练量差异。
- 支持完整预览后一次保存整轮计划，再按日调整或替换；力量与拉伸分别计数，无日期分化计划完成一轮后可以继续使用。
- 底部仅保留开始训练、调整计划及运动记录；设置、可选健身房和教程收纳到左上角菜单，教学保留在选择、预览和训练中。
- 新增中文首次教程和自有后端连接步骤，既有资料可以继续使用；支持跟随系统、浅色和深色外观。
- 按方案保存每项循环计划的本机选择，保持已有任意 N、指定日期、原始 kg/lb、开始时计划和独立实际记录。

## 0.0.1

- 提供完整中文 Android 原生训练应用、Ktor 自有后端和独立 SQLite 数据。
- 支持可配置 N 分化、实际健身房及器械、可选日期计划、未来部位预览与动作替换。
- 收录中文图解教学与按部位及器械匹配的训练、动态及静态拉伸；拉伸由用户选择并指定加入位置。
- 按组保留 kg / lb、单只 / 单侧 / 总重量和负重 / 助力，区分计划目标及真实完成结果。
- 支持完整离线记录、完成及取消、开始时计划保存、联网同步和明确的版本冲突选择。
- 使用安卓定时唤醒发送休息与拉伸到时普通通知，提示音和振动遵循通知设置，展示授权状态及对应系统入口。
- 提供版本化 JSON 与素材 ZIP 备份、开放业务接口、Python CLI 和项目级训练助手 skill。
- 在应用设置中检查正式更新，查看说明和下载进度，下载后通过系统确认覆盖安装并保留训练资料。
