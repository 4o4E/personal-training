# 动作素材

应用内置中文力量动作与拉伸文字资料。动作教学显示主要/辅助部位文字、已有动作图片和 SmartWorkout 动态 MP4；没有可用图片或视频的动作仍显示文字资料。公开来源图片和视频由安卓手机按需直接从来源网站下载并缓存；已缓存媒体可离线查看或播放，首次下载或缓存缺失时需要访问来源网站。自有后端不提供这些公开素材。动作目录、文字说明及动作标识仍保留。

网站来源动作目录不一定按用户选择的健身房或部位筛选。器械条件未知时不要假设动作可用；选择来源动作前应检查教学及器械要求。

## 来源与维护

- [Hevy](https://hevy.com/)：公开动作目录、中文步骤与缩略图。
- [SmartWorkout](https://smartworkout.app/zh/健身练习库)：线上动作教学和视频。
- [RepDB](https://exercise-dataset.com/)：拉伸插画和动作资料。
- [Workout Guide](https://github.com/bryllim/workout-guide)：小腿拉伸 SVG 分帧。
- 主要与辅助部位以文字显示。

动作身份独立于媒体文件。公开来源图片和视频的缓存位于手机，素材文件不保存在自有后端发行包，也不属于后端完整备份；清除手机缓存或更换设备后，可在有网络时从来源网站重新下载。已有动作图片及 SmartWorkout 动态 MP4 仍可查看或播放；没有可用图片或视频的动作显示文字资料。用户上传的器械图片是另一类资料，仍上传至自有后端并纳入后端资料备份。

SmartWorkout 图片及视频地址由动作目录保存，安卓客户端直接向对应来源网站请求媒体。动态 MP4 会下载到设备的可离线复用缓存，不是只保存网页/媒体地址；离线播放已缓存内容，缺失缓存则需重新联网下载。

网站来源目录由 `tools/collect-smartworkout.py` 从公开中文 Sitemap 采集，`tools/build-smartworkout-catalog.py` 根据来源资料生成后端目录和关联报告。后端保留动作目录及文字资料，不存储或代理来源图片、视频。使用网站动作目录仍需连接配套后端；媒体获取则由手机直接连接其来源网站。网络不可用时，内置动作与拉伸文字资料、已有训练记录及已缓存媒体仍可用。
