# 应用使用指南

## 首次连接与离线使用

首次进入应用可通过教程配置后端、通知及定时唤醒权限，也可稍后在「菜单 → 设置」处理。训练与记录可离线使用；连接恢复后再同步。后端地址必须是手机可访问的地址，公网服务应使用 HTTPS。

同步冲突时，手机和服务器两份内容都会保留。需要从「运动记录」的同步入口打开详情，检查双方内容后明确选择，不要把冲突当作自动覆盖。

## 计划与日期安排

在「调整计划」初始化整轮方案及当前分化，可从三、四、五分化候选中选择，也可维护自定义 N 分化、独立计划和指定日期安排。顶部显示下一训练部位及轮换状态；可手动指定下一项，或选择「自动轮换」恢复按实际完成记录计算。预览候选的动作、部位、器械和目标后再确认保存；可选力量动作数及组数，也可增加拉伸并设置顺序、侧别、次数或时长。确认前返回或取消不会保存。未来日期安排用于对应日期的计划预览，不要求每天另行安排训练。

已有计划会优先复用。未配置可复用计划的部位会结合已有日期安排或最近同类实际记录补齐。计划目标与实际记录分开保存，负重保留原单位与含义；未填写负重不表示零重量。

## 开始与调整训练

「开始训练」按 UTC+8 日期进入当天唯一训练记录：继续当天进行中的训练，否则执行当天已准备的计划。上一日仍进行中的训练不阻止新一天。当天完成的记录仍可继续编辑训练；超出原定目标时，需明确追加待执行组。

修改当前训练的未完成内容，从「调整计划 → 调整本次剩余内容」进入；替换或加入的仅影响未完成动作和拉伸，已完成组与实际读数保留。未来计划编辑只影响之后的训练。

每组记录实际读数后保存并按计划休息。一次训练所有有效目标中的最后一组保存后不再开始休息（不是每个动作的最后一组）。同次训练同一动作的后续组会沿用最近完成组的次数、重量和原始 kg/lb 单位；当前未提交草稿优先，首组使用计划目标。常用重量可以选择或增减，手动输入的小数及原始单位不会强制换算。修正已完成组不重启计时；页面导航后返回不会重置读数或休息截止时间。

## 运动记录与健康数据

「运动记录」可查看训练历史、素材、健康数据、小米采集状态、待上传项目与同步冲突。点击同步入口执行同步；有问题时打开详情查看原因和重试。每次训练及其他运动都可以从日期详情查看或修改；用户手动记录或明确导入的其他运动与训练分开保存。小米运动摘要仅在健康详情只读显示，不自动创建或更新用户运动。

日期详情顶部显示全天健康概览；原始采样、睡眠分段及其他身体测量按需展开。健康内容先显示已下载缓存，再按日期刷新；尚未下载不等于没有记录。只有健康数据的日期也可以查看，不会因此标记为完成训练。

训练或其他运动在保存了完整起止时间且有匹配的小米运动采样时显示心率图。图表只使用真实运动采样，不以稀疏日常采样补造曲线；较长采样缺口会断开，缺少匹配样本时会说明。设备运动摘要与用户保存的运动时间、持续时间等字段分别保留。

## 计时与提醒

通知授权影响通知显示，精确定时权限影响系统唤醒能力。首次教程会说明权限及配置入口；未授权时仍可继续使用。实际开始计时且缺少系统所需权限时，应用会说明受影响能力并允许继续，但不保证系统未授权的通知或唤醒功能可用。

休息或拉伸计时基于本机截止时间，不要求后端连接，到时不会自动记录一组完成。休息提醒声音默认关闭；用户选择铃声后使用系统媒体音量并遵循系统勿扰策略。应用或通知可停止提醒；停止提醒不结束额外休息。熄屏时额外休息不逐秒刷新通知，亮屏后按原截止时间显示。应用被强行停止或手机重启后的自动恢复不属于当前计时支持范围。

## 备份、设置与素材

设置中的系统 ZIP 选择器支持本机资料导出/导入；本机资料包可包含设备已下载的健康数据缓存，但公开动作媒体缓存不作为备份保证。完整健康资料需在线通过后端备份。后端完整备份包含业务目录和用户上传图片，不包含从来源网站下载的公开图解、图片或视频；这些缓存可在新设备或缓存清除后重新下载。备份范围及迁移方式见[备份与迁移](backup.md)。

动作教学可在计划预览、动作选择与训练中查看，显示主要/辅助部位文字、已有动作图片和来源视频；无可用图片或视频时显示文字说明。来源图片和动态视频由手机直接从来源网站按需下载并缓存，已有缓存可离线查看或播放；自有后端不提供公开素材。用户上传的器械图片仍通过后端同步。素材来源与细节见[动作素材](media.md)。应用设置可管理外观、后端连接、通知权限及更新。

HTTP 接口及数据格式见[开放接口](API.md)。
