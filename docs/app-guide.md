# 应用使用指南

## 首次连接与离线使用

首次进入应用可通过教程配置后端、通知及定时唤醒权限，也可稍后在「菜单 → 设置」处理。训练与记录可离线使用；连接恢复后再同步。后端地址必须是手机可访问的地址，公网服务应使用 HTTPS。

内置和随 App 提供的网站动作可直接搜索、添加到训练或安排到计划，即使后端未配置或无法连接。首次选择的动作存入手机后再同步。教学图片与视频按需下载，不影响动作保存。

同步冲突时，手机和服务器两份内容都会保留。需要从「运动记录」的同步入口打开详情，检查双方内容后明确选择，不要把冲突当作自动覆盖。

## 计划与日期安排

在「调整计划」初始化整轮方案及当前分化，可从三、四、五分化候选中选择，也可维护自定义 N 分化、独立计划和指定日期安排。顶部显示下一训练部位及轮换状态；可手动指定下一项，或选择「自动轮换」恢复按实际完成记录计算。预览候选的动作、部位、器械和目标后再确认保存；可选力量动作数及组数，也可增加拉伸并设置顺序、侧别、次数或时长。确认前返回或取消不会保存。未来日期安排用于对应日期的计划预览，不要求每天另行安排训练。

已有计划会优先复用。未配置可复用计划的部位会结合已有日期安排或最近同类实际记录补齐。计划目标与实际记录分开保存，负重保留原单位与含义；未填写负重不表示零重量。

## 开始与调整训练

「开始训练」按 UTC+8 日期进入当天唯一训练记录：继续当天进行中的训练，否则执行当天已准备的计划。上一日仍进行中的训练不阻止新一天。当天训练进行中或结束后，可直接向当天训练追加动作或拉伸；只写入当天记录，不改变未来计划。

开始训练时，当前动作左侧优先播放可用的动作动图，右侧输入重量和次数（计时动作则输入秒数）。静态图仍可使用；缺图不影响录入。已有备注可点卡片右上角编辑，没有备注时可通过「更多动作操作 → 添加动作备注」补充。「查看记录」展开完成组，显示重量 × 次数、时长或分段读数，右侧图标可修改或撤销；进度条以每组一个圆点显示进度。

动作卡片上的「更换动作」用于临时换练：还没做的动作原位替换；已经做过的组留在原动作，新动作接替余下目标。「更多动作操作」中的「订正实际动作 / 器械」用于修复选错的记录，保留原实际读数和时间。两种操作都不改变开始时的计划副本或未来计划；也可以从「调整计划 → 调整本次剩余内容」重新安排未完成的动作。

重量、次数及秒数可直接输入，也可点按同框的上下箭头调整一档；长按任一箭头后上下拖动可连续调整。点击重量框内的 `kg` / `lb` 直接切换录入单位，不改动数字；磅制时右侧只显示公斤等值，保存仍用输入的数值和单位。无负重时显示 `0`，不要求标记侧别、负重或助力；已有实际组的历史字段不因界面更新而改变。

每组提交后按计划休息；整次训练所有有效目标中的最后一组不再启动休息。同一动作的下一组默认沿用最近完成组的实际读数，首组使用计划目标，未提交草稿优先。可从「更多动作操作 → 调整实际读数」改本组休息时长；修正已完成组不重启计时。

## 运动记录与健康数据

「运动记录」可查看训练历史、素材、健康数据、小米采集状态、待上传项目与同步冲突。点击同步入口执行同步；有问题时打开详情查看原因和重试。每次训练及其他运动都可以从日期详情查看或修改；用户手动记录或明确导入的其他运动与训练分开保存。小米运动摘要仅在健康详情只读显示，不自动创建或更新用户运动。

手动完成训练时，运动记录以最后一组实际完成的时间为结束时间。已经记过组的训练连续半小时没有更新会自动完成；若系统延后了后台执行，回到 App 时会检查并结算，结束时间仍是最后一组的实际时间。当天仍可继续同一份记录。

训练结束后的「今日训练记录」左侧显示动作图，右侧直接列出各组实际读数。点组记录旁的铅笔可修改读数；需要修改动作备注或订正实际动作与器械时，使用「运动记录」的日期详情。

日期详情顶部显示全天健康概览；原始采样、睡眠分段及其他身体测量按需展开。健康内容先显示已下载缓存，再按日期刷新；尚未下载不等于没有记录。只有健康数据的日期也可以查看，不会因此标记为完成训练。

训练或其他运动在保存了完整起止时间且有匹配的小米运动采样时显示心率图。图表只使用真实运动采样，不以稀疏日常采样补造曲线；较长采样缺口会断开，缺少匹配样本时会说明。设备运动摘要与用户保存的运动时间、持续时间等字段分别保留。

日期详情的「修改」也支持订正实际动作和器械；选择正确动作后，已有实际组的重量、单位、次数和完成时间保留。保存后统计使用订正后的动作，开始时计划副本不变。

## 计时与提醒

通知授权影响通知显示，精确定时权限影响系统唤醒能力。首次教程会说明权限及配置入口；未授权时仍可继续使用。实际开始计时且缺少系统所需权限时，应用会说明受影响能力并允许继续，但不保证系统未授权的通知或唤醒功能可用。

休息或拉伸计时基于本机截止时间，不要求后端连接，到时不会自动记录一组完成。休息提醒声音默认关闭；用户选择铃声后使用系统媒体音量并遵循系统勿扰策略。组间休息到时，用户可在训练页或通知中点击“结束休息”，同时结束计时与提醒；完成下一组也会结束上一段休息。旧休息通知不能影响随后开始的新计时。拉伸计时维持其结束及停止提醒操作。熄屏时额外休息不逐秒刷新通知，亮屏后按原截止时间显示。应用被强行停止或手机重启后的自动恢复不属于当前计时支持范围。

## 备份、设置与素材

在「设置 → 按日期导出数据」勾选需要的项目并设置起止日期（包含两端），可保存 ZIP 或调用系统分享。训练包含手机上未同步的实际记录；健康数据可在线获取，离线时使用已缓存数据并注明缺失范围。此分享包与下面用于恢复的备份不同。

设置中的系统 ZIP 选择器支持本机资料导出/导入；本机资料包可包含设备已下载的健康数据缓存，但公开动作媒体缓存不作为备份保证。完整健康资料需在线通过后端备份。后端完整备份包含业务目录和用户上传图片，不包含从来源网站下载的公开图解、图片或视频；这些缓存可在新设备或缓存清除后重新下载。备份范围及迁移方式见[备份与迁移](backup.md)。

动作教学可在计划预览、动作选择与训练中查看，显示主要/辅助部位文字、已有动作图片和来源视频。缺少可靠教学关联时，可搜索并明确选择教学动作，选择仅用于查看教学，不修改训练动作身份，重新打开详情仍保留本机选择。未连接后端、没有教学关联、请求失败和媒体加载失败分别提示；已有缓存可离线查看，显示缓存时会说明当前请求状态。来源图片和动态视频由手机直接从来源网站按需下载并缓存，自有后端不提供公开素材。历史动作已有明确绳索、哑铃资料时显示对应类别，不能确定的器械条件显示未知，不再当作无需器械。用户上传的器械图片仍通过后端同步。素材来源与细节见[动作素材](media.md)。应用设置可管理外观、后端连接、通知权限及更新。

HTTP 接口及数据格式见[开放接口](API.md)。
